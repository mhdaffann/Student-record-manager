# 🎓 Student Record Manager

A responsive web application to manage student records with search, filtering, sorting, and performance analysis.

## 🚀 Features

- 🔍 Search students by name
- 📚 Filter students by course
- 📊 Filter students by marks
- ↕️ Sort by name and marks
- 👥 Display total students
- 📈 Calculate average marks
- 🏆 Identify the topper
- 📱 Responsive design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
